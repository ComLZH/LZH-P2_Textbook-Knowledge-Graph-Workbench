# 09. 桌面工作台交互与视觉优化实施方案

更新时间：2026-08-23  
状态：已完成；以当前代码、47 项自动化测试和 Windows Qt 视觉快照为准

后续演进：本文的 47 项和旧图谱切换是 2026-08-23 阶段事实。2026-09-13 的当前图谱已升级为关系探索/教材定位双模式、布局版本 6、单层关系分区、教材证据顺序及 G6/Qt 共享端点几何；当前截图与限制见[文档 21](21_关系分区与左向右自动布局可读性优化实施完成报告_20260913.md)。

## 1. 本轮目标

在不改变教材抽取、审查、质量检查、导出和 P4 接口的前提下，重新组织 P2 桌面工作台的信息层级和操作路径，使教师能够更快理解“导入教材 → 配置范围 → 开始分析 → 审查图谱 → 导出结果”的主流程。

本轮必须同时改善：

- 首屏信息密度和视觉层级；
- 核心操作的识别度与禁用原因提示；
- 教材、图谱与审查区域的空间利用；
- 页码范围、任务状态和审查数量的即时反馈；
- 低分辨率窗口下的可用性；
- 键盘、工具提示、焦点和文本复制等基础可访问性。

## 2. 设计原则

1. 业务流程优先：核心动作固定为“导入教材、开始分析、导出结果”，其他动作按上下文出现。
2. 状态可见：未导入、已就绪、分析中、待审查、可导出、失败和取消使用统一状态徽标表达。
3. 内容优先：教材预览和图谱占据主要画布，配置面板可滚动，高级模型配置可折叠。
4. 一致性优先：按钮高度、圆角、间距、文字层级、禁用态和危险操作颜色统一。
5. 离线可用：不新增联网图标依赖，使用 Qt 标准图标和项目内样式。
6. 渐进调整：保留现有控件属性和业务回调，避免视觉改造引入数据链路回归。

## 3. 视觉规范

### 3.1 色彩

| 用途 | 色值 |
| --- | --- |
| 应用背景 | `#F4F7FB` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#172033` |
| 次要文字 | `#64748B` |
| 边框 | `#DCE3ED` |
| 主操作 | `#2563EB` |
| 主操作悬停 | `#1D4ED8` |
| 成功 | `#15803D` |
| 提醒 | `#B45309` |
| 错误/危险 | `#DC2626` |

### 3.2 排版与间距

- 字体沿用 Windows/Qt 系统 UI 字体链并调整字号，避免强制单一字体破坏中文或英文回退。
- 页面标题 20 px/700，区域标题 15 px/700，正文 13 px，辅助文字 12 px。
- 采用 4、8、12、16、24 px 的间距序列，主要控件高度不低于 32 px。
- 卡片圆角 10 px，按钮圆角 7 px，状态徽标为胶囊形。

### 3.3 图标

使用 Qt 标准图标映射以下动作，不引入外部下载：

- 导入教材：打开文件夹；
- 开始分析：播放；
- 导出结果：保存；
- 打开输出目录：目录；
- 上一页/下一页：左右箭头；
- 显示/隐藏 API Key：可见性文本按钮与工具提示；
- 帮助/开发者信息：信息；
- 质量通过、提醒和错误：标准状态图标。

## 4. 布局调整

### 4.1 顶部工作区命令栏

- 左侧显示应用名称、用途说明和当前任务状态徽标。
- 右侧集中放置“导入教材”“开始分析”“导出结果”“输出目录”。
- 菜单栏继续提供文件和帮助入口，核心命令同时设置快捷键。
- 原先分散在左侧的三项执行按钮移出配置表单，避免与字段混排。

### 4.2 左侧步骤式配置

- 使用滚动容器承载配置，低分辨率下不截断底部内容。
- 分为 `01 教材来源`、`02 教材信息`、`03 分析范围`、`04 模型与识别`、`运行记录`。
- 文件路径以名称为主、完整路径作为工具提示，减少长路径挤压。
- 模型与识别区域支持折叠；本地模拟时 API Key 不作为必填视觉焦点。
- API Key 提供显示/隐藏入口，Base URL 提供完整工具提示。

### 4.3 教材预览

- 标题旁显示当前来源状态。
- 未导入时提供明确空状态提示。
- 页码导航收敛为一行，使用箭头图标并实时禁用不可用方向。
- 分析范围使用一条紧凑工具栏，突出当前页是否在范围内。

### 4.4 知识图谱

- 标题旁显示节点数、关系数和待审数量。
- 教材/图谱/全部视图切换只保留一组全局分段控制，不在两个面板重复出现。
- 图谱空状态解释“导入并分析后生成候选图谱”。
- 保留 G6 与旧版图谱切换，标签命名和边框风格统一。

### 4.5 审查区

- 节点、关系、质量和证据标签显示数量或状态摘要。
- 工具栏操作继续按选择和状态动态出现，但主次、通过和危险操作使用不同角色样式。
- 表格启用交替行、整行选择、统一行高和无数据提示。
- 内容分割器保持可拖动，并提供“默认、均衡、专注教材、专注图谱、全部”布局菜单。

## 5. 交互与状态反馈

- `Ctrl+O` 导入教材，`Ctrl+Enter` 开始分析，`Ctrl+Shift+S` 导出结果，`F1` 打开开发者信息。
- 主操作按钮在禁用时保留原因工具提示。
- 模型模式切换时更新 API Key 和 Base URL 的视觉状态与提示。
- 导入后状态变为“已就绪”，分析中变为“分析中”，结果生成后显示“待审查”，完成有效导出后显示“已导出”。
- 分析进度继续使用非阻塞进度对话框，并统一视觉样式。
- 所有会触发删除或批量通过的动作保留原有确认和业务规则，不因样式调整扩大权限。

## 6. 实施顺序

1. 引入应用级样式、字体、标准图标和控件角色属性。
2. 新建顶部命令栏，并把执行按钮从左侧配置区迁出。
3. 将配置区改为可滚动的步骤卡片和可折叠高级配置。
4. 收敛全局视图切换，优化预览导航、图谱摘要和审查标签。
5. 增加任务状态、数量徽标、空状态、快捷键、禁用原因和焦点顺序。
6. 增加界面结构与状态同步测试，执行完整 P2 回归。
7. 真实启动工作台，在空项目、导入教材、开发者弹窗和不同视图布局下做桌面验收。

## 7. 验收条件

- 1480×900 和常见全屏尺寸下无关键控件截断、重叠或不可访问。
- 未导入教材时，核心流程、空状态和按钮禁用原因清楚。
- 导入 PDF 后，文件名称、页码、范围状态、分析按钮和预览同步正确。
- 高级模型区域可展开/折叠，API Key 可切换可见性且默认仍为密码模式。
- 全局视图切换能够专注教材、专注图谱并恢复全部区域。
- 节点、关系、质量和证据标签数量与当前工作簿同步。
- 开发者信息入口、既有分析、审查、导出和布局回调不回归。
- 完整自动化测试通过，并完成真实 Windows 桌面截图和操作验证。

## 8. 非目标

- 本轮不调整 OCR、模型提示词、节点/关系抽取算法和目录层级契约。
- 本轮不替换 G6、PDF 渲染器、Excel 导出或 P4 导入接口。
- 本轮不引入在线字体、在线图标、遥测或新的第三方服务。

## 9. 最终实施结果

- 新增 `src/textbook_builder/ui_theme.py`，集中维护颜色、排版、按钮角色、标签、表格、分割器和进度条样式。
- `desktop_app.py` 已完成命令栏、滚动步骤配置、模型折叠、空状态、全局布局切换、状态同步和审查数量同步。
- 新导入教材会清理旧底稿、图谱、质量结果和布局状态，避免跨来源残留。
- 新增 `tests/test_desktop_ui_spec.py` 的 5 项规格测试，以及 `scripts/capture_workbench_ui.py` 视觉捕获脚本。
- 完整 P2 测试 `47 passed`。
- Windows 原生 Qt 在 1480×900 和 1180×720 下完成空工作台与真实 PDF 已就绪状态截图检查。
- 截图检查发现的字体回退和禁用按钮视觉问题已经修复。

## 10. 后续双视图一致性修正

2026-08-23 实际使用发现：G6 保存的中心点坐标被兼容视图按左上角坐标复用，导致章节框与节卡片覆盖；同时旧 G6 载荷会隐藏端点属于结构节点的真实非层级关系。该问题不改变本文件已经完成的整体界面改造结论，后续修正规则、实现顺序和验收标准统一由 `10_双视图关系一致性与日期导出实施方案.md` 管理。

## 11. 后续 PDF 预览缩放增强

2026-08-24 实际使用确认原 `QPdfView` 只支持普通滚轮浏览，`Ctrl + 滚轮` 仍被当作纵向滚动。现已完成专用缩放组件、可见缩放控件、快捷键、比例边界和响应式控制栏；宽面板中页码/缩放左右同排，窄面板中自动换行。详细契约和最终结果由 `12_PDF预览缩放交互实施方案.md` 管理。
