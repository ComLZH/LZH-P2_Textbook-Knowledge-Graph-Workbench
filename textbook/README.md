# 教材文件输入目录 (Textbook Directory)

本目录用于存放待分析与知识图谱抽取的教材 PDF、图片或结构化输入材料。

### ⚠️ 版权合规说明 (Copyright Notice)
根据开源合规与版权保护原则，本开源仓库**不分发、不附带任何具有专有版权的正式中小学教材原件**。

### 快速使用指引 (How to Use)
1. 将您合法取得的教材电子版（如 `.pdf`、`.png`、`.jpg`）放入此 `textbook/` 目录中。
2. 启动工作台后（双击运行 `启动教材知识图谱工作台.cmd`），点击界面左上角【导入教材】，选中放入此目录的教材文件即可。
3. 工作台默认支持指定页码范围分析（例如 11-13 页），可优先以小切片快速体验知识抽取与图谱构建效果。
